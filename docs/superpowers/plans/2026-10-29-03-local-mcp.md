# Read-Only Local MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow local Codex to search and read OpenWhispr notes and transcripts through MCP without OpenWhispr Pro, cloud API keys or remote server hosting.

**Architecture:** A separately launchable local Node.js stdio MCP adapter invokes the installed `@openwhispr/cli` with `--local`, no shell interpretation. The existing desktop's authenticated localhost CLI bridge remains the only source of note data. MCP exposes read-only bounded tools, with explicit source/approved-version handling once Transcript Studio is implemented.

**Tech Stack:** Node.js >=24, TypeScript, MCP SDK (pin compatible version after verifying package), `@openwhispr/cli`, Node `spawn` with `shell:false`, Node test runner.

**Spec:** `docs/superpowers/specs/2026-10-29-openwhispr-integrated-studio-design.md`

## Global Constraints

- Local `stdio` only, no inbound public HTTP transport, no `--remote` fallback, no hosted MCP entitlement bypass.
- No mutation tools, arbitrary terminal tools, arbitrary file writes, cloud login or token exposure.
- Child-process argv arrays only; strict integers, validated query size, timeouts and bounded output.
- MCP client can read authorized data, which may be sent to its LLM provider: document this explicitly.
- Do not expose local data for a different OS user or account, and do not log note text.

## Review Focus

1. Desktop app not running: return actionable backend-unavailable error, no remote retry. [Task 1]
2. Shell metacharacters in note search: literal argument, never command execution. [Task 1]
3. 100k-character transcript: bounded page results, not oversized MCP response. [Task 3]
4. Negative IDs, malformed JSON, stale CLI versions: readable validation errors. [Task 2]
5. Protected/shared account data outside local account scope: fail closed. [Task 4]

## File Structure

- Create `tools/local-mcp/package.json`, `tools/local-mcp/tsconfig.json`: self-contained build.
- Create `tools/local-mcp/src/cliAdapter.ts`: argv-only, timeout-bound CLI invocation.
- Create `tools/local-mcp/src/commands.ts`: typed read methods and response validation.
- Create `tools/local-mcp/src/server.ts`: MCP tool registration and stdio entry point.
- Create `tools/local-mcp/src/transcriptPaging.ts`: bounded UTF-8/code-point-safe output paging.
- Create `tools/local-mcp/test/*.test.ts`: fake CLI and MCP transport tests.
- Create `docs/custom/local-mcp-setup.md`: install, Codex config, permissions and privacy.
